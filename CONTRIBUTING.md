# Contributing to DMO

Thank you for helping build DMO.

1. Open an issue before starting a large feature or architectural change.
2. Keep audio-engine code independent from UI code.
3. Add tests for timeline calculations and signal-processing behavior.
4. Run `cargo fmt --check`, `cargo test --workspace`, and
   `cargo clippy --workspace --all-targets` before submitting a change.

Please keep pull requests focused. Describe audible or user-visible behavior,
the design trade-offs, and how you verified the change.
